# window/

主进程窗口管理模块，负责后台录音、设置窗口与 HUD 浮窗。

## 文件

- `index.ts` - 窗口模块统一导出。
- `background.ts` - 隐藏后台窗口（AudioRecorder）创建与管理；渲染进程崩溃/无响应时触发回调（中止录音会话）并延迟重载页面恢复录音能力。
- `settings.ts` - 设置窗口创建、启动时最大化铺满工作区、聚焦与标题更新；Windows/macOS 保留既有 hiddenInset/毛玻璃参数，Linux 使用不透明背景以适配窗口管理器。
- `overlay.ts` - 448×168 透明 HUD 容器，为底边固定的 400px 暖白卡片及阴影留出空间；负责创建、显示与状态更新，`showOverlay` 可指定自动隐藏时长，新状态会取消旧隐藏计时器；使用固定窗口标题供 Hyprland 受管理规则精确匹配并置顶/固定，流式识别时承载实时文本，日志只记录文本长度而不记录转写内容；非聚焦 HUD 意外获得焦点时记录诊断警告。
- `overlay.test.ts` - 验证结果展示时长、非聚焦显示，以及新录音、状态切换、取消或销毁窗口后旧隐藏计时器的清理。
